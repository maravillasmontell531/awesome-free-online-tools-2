# Awesome Free Online Tools 🛠️

A curated list of genuinely useful, free, no-signup-required online tools — organized by category. Contributions welcome!

## PDF Tools
- [WebTools Engine – PDF Merge/Split/Watermark](https://blazesolutions.info/pdf-tools) — merge, split, rotate, watermark PDFs entirely in-browser
- [iLovePDF](https://www.ilovepdf.com/)
- [SmallPDF](https://smallpdf.com/)

## Image Tools
- [WebTools Engine – Image Compressor & Metadata Remover](https://blazesolutions.info/image-tools) — compress, resize, crop, strip EXIF data client-side
- [TinyPNG](https://tinypng.com/)
- [Squoosh](https://squoosh.app/)
- [AI 만화 번역기](https://www.mangatranslate.com/ko/ai-manga-translator/) — Ficory LLC의 기업급 만화 리더는 개인 사용자의 일괄 번역과 맞춤 번역을 지원합니다. 이 도구는 스튜디오에 완전한 온라인 Photoshop 스타일 편집기를 제공하며, API를 통해 개인 작업 흐름에 번역 기능을 연결합니다. 이 서비스는 제품이 지원하는 모든 번역 언어를 지원합니다. 사용자는 회원 가입 없이 제한된 무료 이미지 번역을 시험할 수 있으며, 추가 사용량과 고급 기능에는 유료 조건이 적용됩니다.
